2. ผลวิจัยโดยย่อ

ทั้งหมดคือความสัมพันธ์ ไม่ใช่เหตุและผล · ส่วนใหญ่มาจาก IG Reels · หลายบัญชียิงโฆษณาอยู่ แยกวิวจากโฆษณารายคลิปไม่ได้
  1. viora: คลิปที่ไม่ได้ขายชิ้นไหน (ตัวตน วันเกิด/ราศี มู้ดฟิล์ม) ได้วิวสูงกว่าปกติ ข้อค้นพบ มั่นใจปานกลาง–อ่อน
  2. โพสต์ collab กับครีเอเตอร์/แบรนด์อื่นได้วิวสูง (ผ่านเกณฑ์เมื่อรวม 2 แบรนด์) มั่นใจอ่อน
  3. venita: คลิปโชว์สินค้าสั้น 5–10 วินาทีพบมากสุดในคลิปฮิต แต่บอกไม่ได้ว่าเป็นตัวทำให้ฮิต
  4. คลิปที่คนถามซื้อ ≠ คลิปวิวสูง — คนถามซื้อมาจาก "ของมีชิ้นเดียว" / "เจ้าของพาดูแหวนแล้วตอบคนดู"
  5. 3 สูตรเดิม ยังยืนยันไม่ได้สักสูตร — สายมูไม่มีหลักฐานฝั่ง fine jewelry · ไม่เจอสัตว์เลี้ยงเลย · ดาราใส่จริงเจอแค่ 2 คลิป

3. งานเล็กอื่นที่ทำ

  • เช็ก model ของ agent: ไม่มี agent ตัวไหนใช้ Fable แล้ว (ทุกตัวเป็น Opus / Sonnet) ไม่ต้องแก้
  • วิธีเก็บข้อมูลที่ใช้ได้จริง บันทึกไว้ในใบงานให้ครั้งหน้าเร็วขึ้น (IG อ่าน grid + API รายคลิป · TikTok ต้องเปิดผ่านหน้าโปรไฟล์ เพราะโดนบล็อกเมื่อเปิดลิงก์คลิปตรงถี่ๆ)

4. ยังค้าง / รอคุณตัดสิน

  1. เอาผลวิจัยไปปรับบทถ่าย 9 ชิ้น ที่เตรียมไว้ไหม (บทเดิมสร้างบน 3 สูตรที่ยังยืนยันไม่ได้)
  2. เก็บ TikTok ไทยเพิ่ม ในเซสชันหน้า — จุดอ่อนที่สุดของงานนี้ (มีแค่ 2 บัญชี)
  3. ค้างจากก่อนหน้า: เลือกทาง inbox รวม A/B/C · อนุมัติแผน social listening / ลอง Mandala · viora ยังไม่เปิดสวิตช์ข้อความ IG · เปิด LINE Messaging API + webhook
